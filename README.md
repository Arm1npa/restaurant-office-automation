# سیستم اتوماسیون اداری - مجموعه رستورانی

سیستم جامع مدیریت مکاتبات و اسناد برای مجموعه‌های رستورانی با قابلیت‌های پیشرفته گردش کار، تأیید و امضای دیجیتال.

## ✨ ویژگی‌ها

### 📧 مدیریت نامه‌ها
- ایجاد نامه‌های داخلی، وارده و صادره
- شماره‌گذاری خودکار و منحصر به فرد
- اولویت‌بندی (کم، عادی، بالا، فوری)
- سطح محرمانگی (عادی، محرمانه، خیلی محرمانه)
- پیوست فایل‌ها
- تاریخچه کامل تغییرات

### 🔄 گردش کار پویا
- تعریف گردش کارهای سفارشی
- مراحل چندگانه با اقدامات مختلف (تأیید، رد، ارجاع، امضا)
- ارجاع به کاربران یا واحدهای سازمانی
- مدیریت وضعیت نامه‌ها

### ✅ سیستم تأیید و امضا
- تأیید چندمرحله‌ای
- امضای دیجیتال با ثبت اطلاعات کامل
- قفل شدن سند پس از امضا
- جلوگیری از تغییرات پس از امضا

### 📥 صندوق ورودی و خروجی
- مدیریت نامه‌های دریافتی
- فیلتر بر اساس وضعیت (در انتظار، مشاهده شده، تکمیل شده)
- نمایش نامه‌های خوانده نشده
- پیگیری نامه‌های ارسالی

### 🗄️ بایگانی
- بایگانی خودکار نامه‌های تکمیل شده
- جستجو و فیلتر پیشرفته
- دسترسی سریع به سوابق

### 👥 مدیریت کاربران و واحدها
- ساختار سازمانی چندسطحی
- نقش‌های کاربری (مدیر، کارمند، حسابدار، بازرس)
- کنترل دسترسی مبتنی بر نقش (RBAC)
- مدیریت واحدهای سازمانی

### 🔔 سیستم اعلانات
- اعلانات لحظه‌ای
- اعلانات نامه‌های جدید، ارجاعات، تأییدها
- نمایش اعلانات خوانده نشده
- دسترسی سریع از هدر

### 📊 داشبورد تحلیلی
- آمار کلی نامه‌ها
- نمودارهای وضعیت و اولویت
- آخرین نامه‌ها
- اعلانات اخیر

### 📝 گزارش عملکرد (Audit Log)
- ثبت تمام عملیات حساس
- پیگیری تغییرات
- گزارش‌گیری بر اساس عملیات
- اطلاعات کامل (کاربر، زمان، IP)

### 🌙 حالت شب (Dark Mode)
- پشتیبانی کامل از حالت شب
- ذخیره تنظیمات کاربر
- تغییر سریع از هدر

### 🔍 جستجو و فیلتر
- جستجو در موضوع و شماره نامه
- فیلتر بر اساس وضعیت، نوع، اولویت
- فیلتر ترکیبی
- نتایج لحظه‌ای

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js 18+ 
- npm یا yarn

### نصب
```bash
# Clone repository
git clone https://github.com/yourusername/office-automation.git
cd office-automation

# Install dependencies
npm install

# Run development server
npm run dev
```

### Build برای Production
```bash
npm run build
```

فایل‌های build شده در پوشه `dist` قرار می‌گیرند.

```
├── pages/              # صفحات اصلی
│   ├── Login.tsx
│   ├── Dashboard.tsx
│   ├── Inbox.tsx
│   ├── Outbox.tsx
│   ├── Letters.tsx
│   ├── LetterDetail.tsx
│   ├── CreateLetter.tsx
│   ├── Approvals.tsx
│   ├── Archive.tsx
│   ├── Workflows.tsx
│   ├── Users.tsx
│   ├── Departments.tsx
│   ├── AuditLogs.tsx
│   └── Notifications.tsx
├── store/              # State Management
│   └── index.ts        # Store اصلی با localStorage
├── types/              # TypeScript Types
│   └── index.ts
├── utils/              # Utility Functions
│   └── index.ts        # توابع کمکی (تاریخ شمسی، فرمت‌ها)
├── App.tsx             # کامپوننت اصلی با Routing
├── main.tsx            # نقطه ورود
└── index.css           # استایل‌های سراسری
```
